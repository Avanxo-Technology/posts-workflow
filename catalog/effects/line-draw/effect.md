# Trazo que se dibuja
`stroke-dashoffset` de 260 a 0: el trazo de un icono SVG se dibuja. Se usa en los iconos de las fichas.

## Cómo aplicarlo
Path con `stroke-dasharray:260;stroke-dashoffset:260` y `animation:draw .4s … var(--cs) both`.
