# Pop (rebote con giro)
Aparece desde escala .3 con un giro de -8°, rebasa a 1.12 y se asienta. Sirve para etiquetas, chips, precios y sellos pequeños.

## Cómo aplicarlo
`class="k"` y `style="--n:pop;--s:<seg>s;--t:.35s"`. Para varias etiquetas seguidas, escalona `--s` cada ~.12 s.
